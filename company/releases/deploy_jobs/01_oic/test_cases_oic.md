#### 📝 TC-OIC-01: ตรวจสอบเลขประจำตัวประชาชน (Citizen ID 13 Digits)
* **วัตถุประสงค์:** ป้องกันช่องว่าง (Whitespace) หรือข้อมูลเกิน 13 หลัก ทำให้ DB เกิด Error

  2. ในช่องเลขบัตรประชาชน ให้ทดลองกรอก: ` 1111111111119 ` (เคาะ Space หน้าและหลัง)
  3. กรอกชื่อ `กฤษณะ` นามสกุล `วัฒนายนนต์` และเบอร์โทร `0628696603`
  4. กดปุ่ม **"ถัดไป"**
* **สิ่งที่คาดหวัง:** 
  * ระบบตัดช่องว่าง (Trim) อัตโนมัติ บันทึกลงตาราง `Lead` ด้วยค่า `"1111111111119"` พอดี
  * ไม่เกิด Error 500 หรือ Database Column Overflow

#### 📝 TC-OIC-02: ตรวจสอบรูปแบบป้ายทะเบียนรถยนต์ คปภ. (License Plate Regex)
* **วัตถุประสงค์:** กรองป้ายทะเบียนให้เป็นไปตามระเบียบ คปภ.
* **ขั้นตอนการทดสอบ:**
  1. ทดสอบป้ายผิดระเบียบ: กรอก `1234` (ไม่มีตัวอักษรไทย) หรือ `1กข-1234` (มีเครื่องหมายขีด) ➔ ระบบต้องขึ้นเตือนสีแดงทันที
  2. ทดสอบป้ายถูกต้อง: กรอก `1กข1234` หรือ `กข1234` ➔ ระบบต้องอนุญาตให้ไปต่อได้ฉลุย
* **สิ่งที่คาดหวัง:** Regex คปภ. `/^(?=.*[ก-ฮ])([0-9]{1,2})?[ก-๙]+[0-9]{1,4}$/` ตรวจจับถูกต้อง 100%

#### 📝 TC-OIC-03: จำกัดความยาวชื่อ-นามสกุล (Max 120 Runes)
* **ขั้นตอนการทดสอบ:**
  1. กรอกชื่อภาษาไทยที่มีความยาวเกิน 120 ตัวอักษร เช่น `กฤษณะวัฒนายนนต์...` (ยาวมาก)
  2. กดบันทึกข้อมูล
* **สิ่งที่คาดหวัง:** โค้ดตัดสตริงด้วย `[]rune` เหลือ 120 ตัวอักษรพอดี โดยสระบน/ล่าง (เช่น ิ ี ุ ู) ตัวสุดท้ายไม่ขาดเป็นอักขระขยะ

#### 📝 TC-OIC-05: จัดการกรณีไม่ระบุวันเกิด (Birthdate Null Fallback)
* **ขั้นตอนการทดสอบ:**
  1. ดำเนินการซื้อ พ.ร.บ. โดยปล่อยว่างช่องวันเกิด (ไม่ได้เลือกวันที่)
  2. กดบันทึกเพื่อเข้าสู่หน้าชำระเงิน
* **สิ่งที่คาดหวัง:** API ต้องส่งค่า `NULL` เข้า PostgreSQL แทนที่จะส่ง String ว่าง `""` ซึ่งเดิมทำให้ PostgreSQL แครช
